# game-mods

Ready-to-install builds of game mods. One folder per game, one per mod inside it.

| Game | Mod | What it does |
|---|---|---|
| Empyrion: Galactic Survival | [walkonships](empyrion/walkonships/) | Walk around inside ships while they fly |

Downloads are on the [Releases](../../releases) page. Each release tag starts with the game and mod,
for example `empyrion-walkonships-v0.10.6`, so every mod keeps its own version line.
